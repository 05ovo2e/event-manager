# 모임 이벤트 관리 웹 MVP 개발 로드맵

모임 주최자가 모임을 만들고, 초대 링크로 참여자를 모으며, 공지를 전달할 수 있는 웹 서비스

## 핵심 기능

- **구글 로그인**: 기존 Supabase Auth 구현을 재사용하고 로그인 후 대시보드로 이동한다.
- **모임 관리**: 주최자가 모임을 생성, 수정, 삭제하고 내 모임 목록에서 주최한 모임과 참여한 모임을 구분해 본다.
- **초대 링크**: 추측이 어려운 토큰으로 초대 링크를 만들고, 링크로 들어온 사용자를 자동으로 참여자로 등록한다.
- **공지**: 주최자가 공지를 작성, 수정, 삭제하고 참여자는 모임 상세에서 최신순으로 확인한다.

- 기준 문서: `docs/PRD.md`
- 기술 스택: Next.js, React, Supabase Auth/Postgres, Tailwind CSS, shadcn/ui

## 개발 원칙
- 기존 코드와 docs/PRD.md를 확인한 뒤 작업한다.
- 화면을 먼저 더미 데이터로 구현하고, 이후 Supabase를 연결한다.
- 각 Task는 별도 작업 파일로 관리한다.
- 구현 후 `npm run check`, `npm run build`를 실행한다.
- 인증, 권한, 데이터 변경 기능은 Playwright MCP로 확인한다.
- Task 완료 시 체크하고, 다음 작업 전에 진행 상황을 정리한다.

### 공통 검증 명령

- `npm run check`: 타입 체크, 린트, 포맷 검사를 순서대로 실행한다.
- `npm run build`: 프로덕션 빌드를 확인한다.
- `npm run typecheck`, `npm run lint`: 개별 점검이 필요할 때 사용한다.
